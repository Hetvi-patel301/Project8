# NumPy Analyzer

### Description

**NumPy Analyzer** is a simple Python menu-driven program developed using **NumPy and Object-Oriented Programming (OOP)** concepts. It allows users to create and analyze **1D, 2D, and 3D NumPy arrays** and perform different mathematical, searching, sorting, filtering, and statistical operations.

### Features

The project provides the following features:

1. **Create NumPy Arrays**

   * Create 1D arrays
   * Create 2D arrays
   * Create 3D arrays

2. **Indexing and Slicing**

   * Access elements using indexing
   * Perform slicing on 1D, 2D, and 3D arrays

3. **Mathematical Operations**

   * Addition
   * Subtraction
   * Multiplication
   * Division
   * Division-by-zero checking

4. **Combine and Split Arrays**

   * Combine arrays
   * Split arrays into multiple parts

5. **Search, Sort and Filter**

   * Search for a value
   * Sort array values
   * Filter values using conditions:

     * Greater than
     * Less than
     * Equal to
     * Greater than or equal to
     * Less than or equal to

6. **Aggregates and Statistics**

   * Sum
   * Mean
   * Median
   * Standard Deviation
   * Variance
   * Minimum
   * Maximum
   * Percentile
   * Correlation

### OOP Concepts Used

This project demonstrates several Object-Oriented Programming concepts:

* **Class and Object**

* **Private Attribute (`__array`)**
* **Private Method (`__check_array`)**
* **Class Method (`@classmethod`)**
* **Static Method (`@staticmethod`)**
* **Encapsulation**
* **Menu-driven programming**

### Technologies Used

* **Python**

### How to Run

1. Make sure Python is installed.
2. Install NumPy using:

    pip install numpy


3. Save the program as a Python file, for example:


    DataAnalytics.py


4. Run the program:


python DataAnalytics.py

### Main Menu

  1. Create a NumPy Array
  2. Perform Mathematical Operations
  3. Combine or Split Arrays
  4. Search, Sort, or Filter Arrays
  5. Compute Aggregates and Statistics
  6. Exit
